# Use uv for Python environments
date: 2025-01-05
status: accepted
## Context
Homebrew Python plus pip kept producing broken environments.
## Options considered
| option | evidence | falsifier | reversible? |
|---|---|---|---|
| venv + pip | works but slow, manual pins | none | yes |
| uv | installs 10x faster, pins interpreters | breaks on a needed package | yes |
## Decision
uv for every project; no global pip installs.
## Consequences
README of each project documents `uv venv`.
